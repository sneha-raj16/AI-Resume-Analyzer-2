# 🤖 AI Resume Analyzer & Career Mentor

An AI-powered Resume Analysis SaaS application that helps job seekers improve their resumes, optimize ATS compatibility, identify skill gaps, and get personalized career recommendations using Large Language Models (LLMs).

Built with **Streamlit, Python, Groq API, and Llama 3.3 70B**.

---

## 🚀 Features

### 📄 Resume Analysis
- Upload your resume in PDF format
- Extract resume text automatically
- Analyze resume structure and content
- Get AI-powered feedback

### 🎯 ATS Score Prediction
- Calculates resume compatibility with Applicant Tracking Systems
- Highlights improvement areas
- Provides optimization suggestions

### 🧠 AI Resume Review
The AI analyzes:

- Professional summary
- Technical skills
- Projects
- Education
- Experience
- Achievements
- Keywords

---

### 💡 Smart Suggestions

Get recommendations for:

✅ Missing skills  
✅ Better resume wording  
✅ Project improvements  
✅ Achievement optimization  
✅ Industry-relevant keywords  

---

### 💼 Job Role Matching

Select your target role and get:

- Required skills
- Skill gap analysis
- Career improvement suggestions
- Role-specific recommendations

Supported roles:

- Software Engineer
- AI/ML Engineer
- Data Scientist
- Data Analyst
- Web Developer
- Full Stack Developer

---

### 📊 Interactive Dashboard

Includes:

- Resume score visualization
- Skill analysis
- Strengths
- Weaknesses
- Improvement roadmap

### 📑 AI Generated Resume Report

Generate a downloadable PDF report containing:
